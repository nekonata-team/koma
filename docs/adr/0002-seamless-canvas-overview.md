# Overview を別パネルではなく単一キャンバスのシームレス縮小表示とする

Overview は別画面や静止サムネイル一覧（`Board Facing`）を設けず、通常キャンバスをそのまま縮小して全 Sheet と生存中の全 Koma をシームレスに俯瞰・編成する。通常表示と Overview 間でリフローや再生成を起こさず空間の連続性を保つためであり、静止サムネイルキャッシュの導入は実測で負荷が問題になった場合にのみ再検討する。

## Considered Options

- **別パネル + サムネイルキャッシュ（`Board Facing`）**: 表示負荷を抑えやすいが、キャッシュ生成・更新機構が必要になり、通常キャンバスとの連続性が途切れる。
- **単一キャンバスの GPU 縮小表示（採用）**: 視界外 WebView の非表示制御と組み合わせることで、シンプルな構造のままライブ表示と即時ズーム復帰を実現できる。
