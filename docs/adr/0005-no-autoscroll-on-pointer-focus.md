# マウスクリックでのフォーカス移動時は自動スクロールしない

Den Browser と異なり、Koma ではマウスクリックによる Koma フォーカス時に水平ストリップを自動スクロールしない。ポインタ操作の直後にクリック対象やドラッグ開始位置が横へズレるのを防ぎ、見切れを直したい場合のみ横スクロールやセンタリング操作（`c`）に委ねる方針とした。

## Considered Options

- **クリック時も自動スクロールする**: キーボード操作と挙動を揃えられるが、リンククリックやテキスト選択ドラッグ開始時に画面が動いて誤操作を招きやすい。
- **クリック時は自動スクロールしない（採用）**: ポインタ下の要素位置を固定でき、キーボード移動時のみ視界内へ自動スクロールする構成を簡潔に保てる。
